# UI Design System

## Brand

STREET WEAR is modern, bold, minimal, urban, and premium. The interface is high-contrast, editorial, and conversion-focused without becoming visually noisy.

## Palette

| Token | Value | Usage |
| --- | --- | --- |
| Ink | `#000000` | Primary text, primary CTA, strong dividers |
| Paper | `#ffffff` | Primary background |
| Mist | `#f5f5f5` | Secondary panels and section contrast |
| Charcoal | `#111111` | CTA hover and dark surfaces |
| Cement | `#757575` | Secondary text |

## Typography

- Display: Archivo for large uppercase brand and section headings
- Body: Inter for UI, forms, tables, and product copy
- Headings use strong scale, tight line height, and uppercase styling
- UI labels use small uppercase tracking for premium retail rhythm

## Components

- Sticky header with brand mark, navigation, smart search, account, cart, and theme controls
- Product cards with campaign imagery, badges, wishlist, rating, sale pricing, and quick add
- Filter controls with category buttons, price slider, color swatches, size grid, sorting, and pagination
- Product detail gallery with thumbnails, zoom modal, variant selection, quantity controls, and trust indicators
- Cart and checkout summaries with coupon, shipping, tax, and total
- Admin tables and operational panels optimized for scanning

## Responsive Rules

- Mobile-first spacing and single-column flows
- Product grids adapt from one column to four columns
- Cart and checkout summaries become sticky sidebars on large screens
- Filters move into a mobile drawer below desktop widths
- Text uses fixed responsive breakpoints rather than viewport-scaled font sizes
